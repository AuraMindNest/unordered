[[unordered_node_set]]
== 类模板 unordered_node_set

`boost::unordered_node_set` —
一种基于节点的开放寻址无序关联容器，用于存储唯一值。

`boost::unordered_node_set` 使用类似 `boost::unordered_flat_set`
的开放寻址布局，但由于基于节点，它提供了指针稳定性和节点处理功能。其性能介于
`boost::unordered_set` 和 `boost::unordered_flat_set` 之间。

由于采用开放寻址，`boost::unordered_node_set` 的接口在多个方面与
`boost::unordered_set`/`std::unordered_set` 不同：

* `begin()` 不是常数时间操作。
* 没有用于桶处理的 API（除了 `bucket_count`）。
* 容器的最大负载因子由内部管理，用户无法设置。

除此之外，`boost::unordered_node_set`
基本上是标准无序关联容器的直接替代品。

[[unordered_node_set_description]]
=== 描述

*模板参数*

[width="100%",cols="50%,50%",]
|===
|_键_ |`Key`
必须可从容器中https://en.cppreference.com/w/cpp/named_req/Erasable[擦除]。

|_哈希函数_ |一种作为 `Key`
哈希函数的一元函数对象类型。该函数对象接受单个 `Key` 类型的参数，并返回
`std::size_t` 类型的值。

|_Pred_ |二元函数对象，用于在类型为 `Key`
的值上诱导等价关系。它接受两个类型为 `Key` 的参数，并返回一个类型为
`bool` 的值。

|_Allocator_
|分配器，其值类型与容器的值类型相同。支持使用https://en.cppreference.com/w/cpp/named_req/Allocator#Fancy_pointers[花式指针]的分配器。
|===

容器的元素节点保存在内部的__桶数组__中。节点根据其元素的哈希码插入到确定的桶中，但如果桶已被占用（_冲突_），则使用原始位置附近的可用桶。

桶数组的大小可以通过调用 `insert`/`emplace` 自动增加，或者通过调用
`rehash`/`reserve`
来增加。容器的__负载因子__（元素数量除以桶数量）永远不会大于
`max_load_factor()`，除非在较小尺寸时，实现可能允许更高的负载。

如果
link:../../../../../container_hash/doc/html/hash.html#ref_hash_is_avalanchinghash[`hash_is_avalanching`]`<Hash>::value`
为
`true`，则直接使用哈希函数；否则，会添加一个位混合后处理阶段，以提高哈希质量，但会牺牲额外的计算成本。

[[unordered_node_set_deduction_guides]]
=== 推导指引

如果以下任一条件为真，则推导指引不参与重载决议：

* 它具有 `InputIterator`
模板参数，且为该参数推导出的类型不符合输入迭代器要求。
* 它具有 `Allocator` 模板参数，且为该参数推导出的类型不符合分配器要求。
* 它具有 `Hash`
模板参数，且为该参数推导出的类型是整数类型或符合分配器要求的类型。
* 它具有 `Pred` 模板参数，且为该参数推导出的类型符合分配器要求。

推导指引中的 `size_­type` 参数类型引用由推导指引推导出的容器类型的
`size_­type` 成员类型。其默认值与所选构造函数的默认值一致。

[[unordered_node_set_iter_value_type]]
==== _iter-value-type_

....
template<class InputIterator>
  using iter-value-type =
    typename std::iterator_traits<InputIterator>::value_type; // 仅用于说明
