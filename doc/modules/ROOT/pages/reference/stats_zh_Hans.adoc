[#stats]
== 统计

:idprefix: stats_

开放寻址和并发容器可配置为持续统计受所提供哈希函数质量影响的某些内部操作。

=== 概要

[listing, subs="+macros,+quotes"]
-----
struct xref:#stats_stats_summary_type[__统计摘要类型__]
{
  double 平均值;
  double 方差;
  double 标准差;
};

struct xref:#stats_insertion_stats_type[__插入统计类型__]
{
  std::size_t        计数;
  xref:#stats_stats_summary_type[__统计摘要类型__] 探测长度;
};

struct xref:stats_lookup_stats_type[__查找统计类型__]
{
  std::size_t        计数;
  xref:#stats_stats_summary_type[__统计摘要类型__] 探测长度;
  xref:#stats_stats_summary_type[__统计摘要类型__] 比较次数;
};

struct xref:reference/stats.adoc#stats_stats_type[__统计类型__]
{
  xref:#stats_insertion_stats_type[__插入统计类型__] 插入;
  xref:stats_lookup_stats_type[__查找统计类型__]    成功查找,
                       失败查找;
};
-----

==== __统计摘要类型__

提供数值序列的平均值、方差和标准差。

==== __插入统计类型__

提供容器执行的插入操作次数及相关__探测长度__的统计信息（每次操作访问的xref:structures.adoc#structures_open_addressing_containers[桶组]数量）。

==== __查找统计类型__

对于成功（找到元素）或失败（未找到）的查找，提供容器执行的操作次数及相关__探测长度__（访问的xref:structures.adoc#structures_open_addressing_containers[桶组]数量）以及每次操作的元素比较次数的统计信息。

==== __统计类型__

提供容器执行的插入、成功及失败查找的统计信息。若提供的哈希函数质量良好，则：

* 平均探测长度应接近1.0。
* 对于成功查找，平均元素比较次数应接近1.0。
* 对于失败查找，平均元素比较次数应接近0.0。

这些统计信息可用于判断给定哈希函数是否可标记为link:../../../../../container_hash/doc/html/hash.html#ref_hash_is_avalanchinghash[__雪崩式__]。
