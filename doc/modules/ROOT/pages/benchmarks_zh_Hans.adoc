[[benchmarks_boostunordered_multiset]]
== boost::unordered_[multi]set

所有基准测试均使用`unordered_set<unsigned int>`(非重复元素）
和`unordered_multiset<unsigned int>`（重复元素）创建。源代码可https://github.com/boostorg/boost_unordered_benchmarks/tree/boost_unordered_set[在此处查看]。

插入基准测试插入`n`个随机值，其中`n`范围在10,000至300万之间。对于重复元素测试，相同随机值平均重复5次。

擦除基准测试随机擦除所有`n`个元素直至容器为空。按键擦除使用`erase(const key_type&)`在每次操作中移除整组等价元素。

成功查找基准测试通过按原始插入顺序查找所有`n`个值完成。

失败查找基准测试使用不同种子值生成的`n`个随机整数进行。

[[benchmarks_boostunordered_flatnode_map]]
== boost::unordered_(flat|node)_map

所有基准测试均使用以下类型创建：

* https://abseil.io/docs/cpp/guides/container[`absl::flat_hash_map`]`<uint64_t, uint64_t>`
* `boost::unordered_map<uint64_t, uint64_t>`
* `boost::unordered_flat_map<uint64_t, uint64_t>`
* `boost::unordered_node_map<uint64_t, uint64_t>`

源代码可https://github.com/boostorg/boost_unordered_benchmarks/tree/boost_unordered_flat_map[在此处查看]。

插入基准测试插入`n`个随机值，其中`n`范围在10,000至1000万之间。

擦除基准测试遍历`n`个元素并擦除键值为奇数的元素（平均占50%）。

成功查找基准测试通过按原始插入顺序查找所有`n`个值完成。

失败查找基准测试使用不同种子值生成的`n`个随机整数进行。

[[benchmarks_boostconcurrent_flatnode_map]]
== boost::concurrent_(flat|node)_map

所有基准测试均使用以下类型创建：

* https://spec.oneapi.io/versions/latest/elements/oneTBB/source/containers/concurrent_hash_map_cls.html[`oneapi::tbb::concurrent_hash_map`]`<int, int>`
* https://github.com/greg7mdp/gtl/blob/main/docs/phmap.md[`gtl::parallel_flat_hash_map`]`<int, int>`（含64个子映射）
* `boost::concurrent_flat_map<int, int>`
* `boost::concurrent_node_map<int, int>`

源代码可https://github.com/boostorg/boost_unordered_benchmarks/tree/boost_concurrent_flat_map[在此处查看]。

基准测试使用__T__个线程（1至16之间）并发执行随机选择的**更新**、**成功查找**和**失败查找**操作。操作使用的键遵循https://en.wikipedia.org/wiki/Zipf%27s_law#Formal_definition[齐夫分布]，具有不同的__偏斜__参数：偏斜值越高，键在覆盖范围内的低值区域越集中。

`boost::concurrent_flat_map`和`boost::concurrent_node_map`同时使用常规link:concurrent.html#concurrent_bulk_visitation[批量访问]：在后一种情况下，查找键缓存在本地数组中，当缓冲区达到link:reference/concurrent_flat_map.html#concurrent_flat_map_constants[`bulk_visit_size`]时统一处理。
