[[debuggability_visual_studio_natvis]]
== Visual Studio Natvis

所有容器和迭代器在 Natvis 框架中均具备自定义可视化功能。

[[debuggability_using_in_your_project]]
=== 在项目中使用

若要在项目中通过 Natvis 框架实现 Boost.Unordered
容器的可视化调试，只需将文件
https://github.com/boostorg/unordered/blob/develop/extra/boost_unordered.natvis[/extra/boost_unordered.natvis]
作为"现有项"添加到 Visual Studio 项目中即可。

[[debuggability_visualization_structure]]
=== 可视化结构

可视化方案与标准无序容器保持一致。容器单次最多显示 100
个元素。集合类容器中每个元素的项名称显示为 `[i]`（其中`i` 为从 `0`
开始的显示索引）。映射元素默认显示为
`[{键值显示}]`，例如当首元素为键值对 `("abc", 1)` 时，其项名称将显示为
`["abc"]`。用户可通过启用"ShowElementsByIndex"视图模式切换为按索引命名元素，此视图命名规则与标准无序容器保持一致。

默认情况下，封闭寻址容器将显示 `[hash_function]`、`[key_eq]`、适用的
`[spare_hash_function]` 与 `[spare_key_eq]`、`[allocator]`
及元素列表。若启用用"detailed"视图将额外显示 `[bucket_count]` 和
`[max_load_factor]`信息；若启用"simple"视图，则仅显示元素列表而不包含其他条目。

默认情况下，开放寻址容器显示
`[hash_function]`、`[key_eq]`、`[allocator]`
及元素。使用"simple"视图仅显示元素。无论 SIMD 还是非 SIMD 实现，均可通过
Natvis 框架查看。

迭代器显示方式与标准迭代器类似：指向元素的迭代器显示为元素值；结束迭代器显示为
`{ 结束迭代器 }`。

[[debuggability_fancy_pointers]]
=== 花式指针

容器可视化支持分配器中使用花式指针（如
`boost::interprocess::offset_ptr`）。Boost.Unordered 通过 Natvis
定制点支持各类花式指针。`boost::interprocess::offset_ptr` 已在
Boost.Interprocess 库中预定义支持，自定义类型支持方法请参阅文件
https://github.com/boostorg/unordered/blob/develop/extra/boost_unordered.natvis[/extra/boost_unordered.natvis]
末尾注释。

[[debuggability_gdb_pretty_printers]]
== GDB 美观打印器

所有容器和迭代器均配备自定义 GDB 美观打印器。

[[debuggability_using_in_your_project_2]]
=== 在项目中使用

使用美观打印器前需启用格式化输出（通常为一次性设置）：

[source,highlight]
----
(gdb) set print pretty on
----

默认情况下，ELF 格式二进制文件将嵌入 Boost.Unordered
美观打印器。启用自动加载需执行以下命令（每次启动 GDB 时执行或添加到
".gdbinit" 文件）：

[source,highlight]
----
(gdb) add-auto-load-safe-path [/可执行文件路径]
----

定义 `BOOST_ALL_NO_EMBEDDED_GDB_SCRIPTS` 可禁用所有 Boost
库的内嵌美观打印器。

可通过外部 Python 脚本加载非嵌入版美观打印器：使用 `source` 命令添加脚本
https://github.com/boostorg/unordered/blob/develop/extra/boost_unordered_printers.py[/extra/boost_unordered_printers.py]：

[source,highlight]
----
(gdb) source [/boost路径]/libs/unordered/extra/boost_unordered_printers.py
----

[[debuggability_visualization_structure_2]]
=== 可视化结构

可视化方案与标准无序容器一致：映射容器显示键到映射值的关联；集合容器显示索引到值的关联；迭代器显示为元素值或结束迭代器。示例如下（`boost::unordered_map`、`boost::unordered_set`
及其迭代器）：

[source,highlight]
----
(gdb) print example_unordered_map
$1 = boost::unordered_map 含 3 个元素 = {["C"] = "c", ["B"] = "b", ["A"] = "a"}
(gdb) print example_unordered_map_begin
$2 = 迭代器 = { {first = "C", second = "c"} }
(gdb) print example_unordered_map_end
$3 = 迭代器 = { 结束迭代器 }
(gdb) print example_unordered_set
$4 = boost::unordered_set 含 3 个元素 = {[0] = "c", [1] = "b", [2] = "a"}
(gdb) print example_unordered_set_begin
$5 = 迭代器 = { "c" }
(gdb) print example_unordered_set_end
$6 = 迭代器 = { 结束迭代器 }
----

其他容器显示规则相同（仅需替换模板名称）。注意：子元素（键/映射值/值）的显示取决于其自身的打印设置（可能包含独立的美观打印器）。

无论 SIMD 还是非 SIMD 实现，均可通过 GDB 美观打印器查看。

对启用link:hash_quality.html#hash_quality_container_statistics[容器统计]的开放寻址容器，可在
GDB 中调用 `get_stats()` 获取统计信息。此方法通过
https://sourceware.org/gdb/current/onlinedocs/gdb.html/Xmethod-API.html[xmethod]
实现，不会触发 C++ 同步代码。输出格式示例如下：

[source,highlight]
----
(gdb) print example_flat_map.get_stats()
$1 = [统计] = {[插入] = {[计数] = 5, [探测长度] = {平均值 = 1.0, 方差 = 0.0, 标准差 = 0.0}},
  [成功查找] = {[计数] = 0, [探测长度] = {平均值 = 0.0, 方差 = 0.0, 标准差 = 0.0},
    [比较次数] = {平均值 = 0.0, 方差 = 0.0, 标准差 = 0.0}}, [失败查找] = {[计数] = 5,
    [探测长度] = {平均值 = 1.0, 方差 = 0.0, 标准差 = 0.0},
    [比较次数] = {平均值 = 0.0, 方差 = 0.0, 标准差 = 0.0}}}
----

Boost.Interprocess 库中预定义支持，自定义类型支持方法请参阅文件
https://github.com/boostorg/unordered/blob/develop/extra/boost_unordered_printers.py[/extra/boost_unordered_printers.py]
