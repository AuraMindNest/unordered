= 基准测试

== boost::unordered_[multi]set

所有基准测试均使用 `unordered_set<unsigned int>`（非重复元素）和 `unordered_multiset<unsigned int>`（重复元素）创建。源代码可https://github.com/boostorg/boost_unordered_benchmarks/tree/boost_unordered_set[在此处找到^]。

插入基准测试插入 `n` 个随机值，其中 `n` 介于 10,000 到 300 万之间。对于重复元素的基准测试，相同的随机值平均重复 5 次。

删除基准测试随机删除所有 `n` 个元素，直到容器为空。按键删除使用 `erase(const key_type&)` 在每次操作中移除整个等效元素组。

成功查找基准测试通过按原始插入顺序查找所有 `n` 个值来完成。

失败查找基准测试使用 `n` 个随机生成的整数，但使用不同的种子值。

== boost::unordered_(flat|node)_map

所有基准测试均使用以下容器创建：

* `https://abseil.io/docs/cpp/guides/container[absl::flat_hash_map^]<uint64_t, uint64_t>`
* `boost::unordered_map<uint64_t, uint64_t>`
* `boost::unordered_flat_map<uint64_t, uint64_t>`
* `boost::unordered_node_map<uint64_t, uint64_t>`

源代码可https://github.com/boostorg/boost_unordered_benchmarks/tree/boost_unordered_flat_map[在此处找到^]。

插入基准测试插入 `n` 个随机值，其中 `n` 介于 10,000 到 1000 万之间。

删除基准测试遍历所有 `n` 个元素，并删除键为奇数的元素（平均占 50%）。

成功查找基准测试通过按原始插入顺序查找所有 `n` 个值来完成。

失败查找基准测试使用 `n` 个随机生成的整数，但使用不同的种子值。

== boost::concurrent_(flat|node)_map

所有基准测试均使用以下容器创建：

* `https://spec.oneapi.io/versions/latest/elements/oneTBB/source/containers/concurrent_hash_map_cls.html[oneapi::tbb::concurrent_hash_map^]<int, int>`
* `https://github.com/greg7mdp/gtl/blob/main/docs/phmap.md[gtl::parallel_flat_hash_map^]<int, int>`，包含 64 个子映射
* `boost::concurrent_flat_map<int, int>`
* `boost::concurrent_node_map<int, int>`

源代码可https://github.com/boostorg/boost_unordered_benchmarks/tree/boost_concurrent_flat_map[在此处找到^]。

基准测试使用 _T_ 个线程（1 到 16 之间）并发执行随机选择的操作，包括**更新**、**成功查找**和**失败查找**。操作中使用的键遵循https://en.wikipedia.org/wiki/Zipf%27s_law#Formal_definition[Zipf 分布^]，具有不同的 _skew_ 参数：偏斜度越高，键值越集中在取值范围内的较低值部分。

`boost::concurrent_flat_map` 和 `boost::concurrent_node_map` 均使用常规方式和 xref:concurrent.adoc#concurrent_bulk_visitation[批量访问]进行测试：在后者情况下，查找键被缓存在本地数组中，每次当缓冲区达到 `xref:reference/concurrent_flat_map.adoc#concurrent_flat_map_constants[bulk_visit_size]` 时一次性处理。
